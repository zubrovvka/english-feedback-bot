# English Feedback & ReWord Trainer 🤖🇬🇧

Персональный тренажер английского языка для автоматической обработки досок обратной связи с репетитором (Miro).
Поддерживает два режима: **локальный веб-тренажер в браузере (без Telegram)** и классический Telegram-бот.

---

## 🌐 Вариант 1. Локальный веб-тренажер (БЕЗ Telegram, в 1 клик):
Не требует регистрации ботов в BotFather и Telegram-токенов.
1. Дважды кликни по файлу **`run_web.bat`** (или выполни `python app.py`).
2. Браузер сам откроется по адресу `http://localhost:5000`.
3. **Как закидывать уроки:** Сделай скриншот Miro (`Win + Shift + S`) и нажми `Ctrl + V` в окне браузера.
4. **Горячие клавиши:**
   - `Пробел` — показать ответ;
   - `1`, `2`, `3` — оценить сложность (SuperMemo-2);
   - `P` — послушать озвучку носителя.

---

## 🤖 Вариант 2. Запуск через Telegram-бота:
1. Заполни `TELEGRAM_BOT_TOKEN` в файле `.env`.
2. Дважды кликни по файлу **`run.bat`** (или выполни `python bot.py`).

## 🚀 Что умеет бот:
1. **Приём скриншота в 1 клик:** Скинул фото доски Miro прямо в Telegram — бот распознает все 4 колонки:
   - 🔤 **New Vocab (как в ReWord):** Новые слова, транскрипция, перевод, пример использования.
   - ❌ **Corrections (Разбор ошибок):** Тест «найди и исправь ошибку», объяснение правила (почему *buy some time*, а не *win*).
   - ⭐ **Good Language (Закрепление):** Закрепление удачных выражений с урока в активную память.
   - 💡 **Suggestions (Level Up):** Продвинутые синонимы вместо базовых слов (frustrated/upset вместо sad).
2. **🔊 Нативная озвучка носителя (Edge-TTS):** Кнопка озвучки генерирует аудио с чистым американским/британским акцентом.
3. **Интервальное повторение (SM-2 / SuperMemo):** Бот сам рассчитывает интервалы (1 день, 3 дня, неделя) на основе твоих оценок (🔴 Забыл / 🟡 С трудом / 🟢 Знаю).
4. **Работает везде:** С компьютера или твоего сервера. Учить можно с телефона в Telegram.

---

## 🛠 Настройка за 3 минуты:

### Шаг 1. Получить токен Telegram-бота (бесплатно, 1 минута)
1. Открой Telegram и найди бота [@BotFather](https://t.me/BotFather).
2. Отправь команду `/newbot`, укажи имя и юзернейм (например, `my_english_trainer_bot`).
3. Скопируй полученный HTTP API Token.

### Шаг 2. Получить ключ Gemini API (бесплатно, 1 минута)
1. Зайди на [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Нажми кнопку **"Create API Key"** (карта не требуется, бесплатно до 1500 запросов в сутки).
3. Скопируй ключ.

### Шаг 3. Заполнить файл `.env`
Открой файл `.env` в папке бота и вставь ключи:
```ini
TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
GEMINI_API_KEY=твой_ключ_от_Google_AI_Studio
TTS_VOICE=en-US-JennyNeural
```

## ▶️ Запуск:

### На Windows:
Дважды кликни по файлу `run.bat` (или выполни `python bot.py` в терминале).

### На сервере (Linux / Ubuntu):
```bash
# Установка зависимостей:
pip install -r requirements.txt

# Запуск в фоне (через nohup или tmux / systemd):
nohup python3 bot.py > bot.log 2>&1 &
```
