# 🎓 TutorCards — Персональный Active Recall тренажер английского

Автономный веб-тренажер для автоматического превращения досок с уроков с репетитором (Miro / скриншоты) в интерактивные карточки интервального повторения.
Работает локально на компьютере и доступен с телефона по домашней сети Wi-Fi (PWA).

---

## 🚀 Быстрый запуск в 1 клик

1. Дважды кликни по файлу **`run.bat`** (или выполни `python app.py`).
2. Браузер автоматически откроется по адресу `http://localhost:5000`.
3. **Как добавить урок:**
   - Сделай скриншот доски Miro (`Win + Shift + S`).
   - Нажми `Ctrl + V` в окне тренажера.
   - Нейросеть Gemini Vision сама распознает колонки (New vocab, Corrections, Good language, Suggestions), переведет и разложит по карточкам.

---

## 📱 Тренировка с телефона (Wi-Fi)

При запуске в консоли отображается ваш локальный IP-адрес для мобильных устройств:
```text
[*] На компьютере:     http://127.0.0.1:5000
[*] С телефона (Wi-Fi): http://192.168.x.x:5000
```
- **Защита PIN-кодом:** Чтобы посторонние в Wi-Fi сети не имели доступа к карточкам, укажите PIN-код в `.env` (`ACCESS_PIN=1234`) или во вкладке **⚙️ Настройки** веб-интерфейса.

---

## 🧠 Режимы тренировки (Active Recall)

1. **🎴 Карточки (SuperMemo-2):**
   - Классический интервальный тренажер как в Anki / ReWord.
   - Оценка кнопками `1` (Забыл), `2` (Сложно), `3` (Легко).
   - Алгоритм сам рассчитывает оптимальные дни повторения.
2. **✍️ Вставь пропуск (Cloze Deletion):**
   - Тренировка контекстной памяти: предложение с урока с закрытым целевым словом.
   - Подсказки по первым буквам и проверка с учетом мелких опечаток (расстояние Левенштейна).
3. **⚡ Экспресс-квиз 4 варианта:**
   - Быстрый выбор правильного перевода или формы с динамическими дистракторами и подсчетом серии правильных ответов (Streak).
4. **🔊 Нативная озвучка носителя (Edge-TTS):**
   - Озвучка фраз чистым британским или американским акцентом (кнопка `P` или значок 🔊).
   - Автоматическое кэширование аудиофайлов.

---

## ⌨️ Горячие клавиши (на компьютере)

* `Пробел` — показать / скрыть ответ карточки;
* `1`, `2`, `3` — оценить сложность (SuperMemo-2);
* `P` — послушать произношение носителя;
* `Ctrl + V` — мгновенно загрузить скриншот из буфера обмена.

---

## 🛠 Настройка (бесплатно, 1 минута)

1. Получи бесплатный ключ Gemini API на [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Создай файл `.env` в корне проекта (или введи ключ прямо в интерфейсе тренажера в разделе **⚙️ Настройки**):
```ini
GEMINI_API_KEY=твой_ключ_от_Google_AI_Studio
ACCESS_PIN=1234
TTS_VOICE=en-US-JennyNeural
```
